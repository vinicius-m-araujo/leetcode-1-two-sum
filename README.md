# Desafio LeetCode: 1. Two Sum

Este repositório é dedicado à minha solução para o problema **[1. Two Sum](https://leetcode.com/problems/two-sum/)** do LeetCode.

## 📝 Descrição do Problema

Dado um array de inteiros `nums` e um inteiro `target`, retorne os **índices** dos dois números cuja soma seja igual a `target`.

Você pode assumir que cada entrada terá **exatamente uma solução**, e você não pode usar o mesmo elemento duas vezes. A resposta pode ser retornada em qualquer ordem.

### Exemplos

**Exemplo 1:**
* **Input:** `nums = [2, 7, 11, 15]`, `target = 9`
* **Output:** `[0, 1]`
* **Explicação:** Como `nums[0] + nums[1] == 9`, retornamos `[0, 1]`.

**Exemplo 2:**
* **Input:** `nums = [3, 2, 4]`, `target = 6`
* **Output:** `[1, 2]`

### Constraints (Restrições)

* `2 <= nums.length <= 104`
* `-109 <= nums[i] <= 109`
* `-109 <= target <= 109`
* Apenas uma resposta válida existe.
